    [1,2,3,2,5]

## 多种解法
- 双重循环去重 
- indexOf 去重 
    - 数组的下标，原来数组的index比较
    - 当前项 和res数组里比较 -1留下
- 先排序，相邻比较：当前项和前一项 
    时间复杂度是O（nlongN）
    缺点是数组的稳定性被破坏了

- hash map  ｜ 对象字面量属性去重 
    数据结构的一种
    时间复杂度 O（n） -优点 
    用空间换时间  -缺点
    数据结构：解决特点问题的数据存储结构和特定行为
- Set 去重
    专有的数据结构  
    优点：时间复杂度O(n) 
    不重复的数据容器 
- es6 新增数据结构 
    Map（Hash Map）
    Set (Set)
