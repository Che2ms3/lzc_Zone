## prompt 设计过程
-创建一个网页来生成（goal）
    当姓名，年龄，爱好成功输入时（input），它应该会给我返回一条有趣的信息(output)

如果不满意，接着prompt
-加上节日风格的标题配色，
-把卡片放在右侧，让它看起来像内页 （Layout）
-在页面的顶部加一个有趣的标题，不要替换掉原来的卡片，保留并叠放在新卡片的下方。 Features 
AI写代码通常从一组基本指令开始,不是随随便便的
Prompt 基本块
Goal+Input+Output+Layout+Features=Prompt

创建一个网页来帮我生成生日贺卡
当我输入一个人的姓名，年龄，爱好，特征等时，它应该会给我返回一条有趣的信息
使用喜庆的标题和配色
把卡片放在右侧，让它看起来像贺卡内页
在页面的顶部加一个有趣的标题
另外不要替换旧的贺卡，保留显示状态并叠放在新卡片的下方
